# ☀️ Сандар сөйлейді

Интерактивная образовательная платформа на казахском языке: серия анимационных упражнений с двигательными, тактильными и речевыми заданиями для тренировки счёта у детей младшего школьного возраста.

Учебно-демонстрационный проект. Без backend, без базы данных, без авторизации — всё хранится локально в браузере (`localStorage`).

## Технологии

- React 19 + TypeScript + Vite
- Tailwind CSS 4
- Framer Motion
- Lucide React
- Web Speech API (озвучка инструкций)
- Web Audio API (звуковые эффекты)
- Готовая казахская озвучка чисел 0–10 (см. раздел «Озвучка чисел» ниже)
- [@mediapipe/tasks-vision](https://developers.google.com/mediapipe) — распознавание пальцев рук через камеру (опционально, в упражнениях «Лақтыр да, сана!», «Саусақтар сөйлейді», «Сиқырлы сегіздік»)

## Упражнения

1. **Лақтыр да, сана!** — последовательный счёт 1→10 и 10→1
2. **Жұп па, тақ па?** — чётные и нечётные числа
3. **Есепте де, лақтыр!** — сложение и вычитание в пределах 10
4. **Саусақтар сөйлейді** — счёт на пальцах (клик или камера)
5. **Санның құрамын көрсет** — состав числа
6. **Сиқырлы сегіздік** — траектория-восьмёрка, зрительно-моторная координация

## Камера и MediaPipe

Упражнения с режимом «Камерамен» используют локальное распознавание руки прямо в браузере (ничего не отправляется на сервер). При первом включении камеры один раз подгружаются модель и WASM-рантайм MediaPipe с CDN — дальше работает из кеша браузера. Доступ к камере запрашивается только по явному нажатию кнопки «Камераны қосу» и требует `localhost`/`https` (ограничение браузеров на `getUserMedia`).

## Озвучка чисел

Каждое число, с которым работает ребёнок (счёт, выбранная цифра, ответ, точка на восьмёрке и т.д.), проговаривается вслух на казахском — автоматически, без лишних нажатий. Это не Web Speech API (голосов для казахского там почти нигде нет), а заранее сгенерированные аудиофайлы `public/audio/numbers-kk/0.mp3… 10.mp3`.

Файлы озвучены один раз локально через открытую модель [facebook/mms-tts-kaz](https://huggingface.co/facebook/mms-tts-kaz) (проект Meta MMS, без платных API и без отправки данных куда-либо) и просто воспроизводятся в браузере через `useNumberVoice` — никакой модели в рантайме приложения нет, только обычные mp3.

Модель стохастическая: одно и то же слово с разным random seed звучит то чётко, то смазанно. Поэтому для каждого числа подобран конкретный seed — перебором ~30 вариантов на слово с самопроверкой через локальное распознавание речи (`scripts/search-kk-number-seed.py`, нужен ещё `faster-whisper`), после чего `scripts/generate-kk-numbers.py` синтезирует финальные mp3 с этими seed'ами. Если какое-то слово всё ещё звучит нечётко — перезапусти поиск для него (`python scripts/search-kk-number-seed.py --word үш --seeds 60`) и подставь найденный seed в `WORDS` в `generate-kk-numbers.py`.

## Известные ограничения

- Распознавание большого пальца менее надёжно, чем остальных четырёх — у него другая кинематика сустава.
- Казахский голос для Web Speech API есть не во всех браузерах; при его отсутствии кнопка озвучки скрыта/неактивна, но текстовая инструкция всегда доступна.
- Камере нужен один сеанс интернета при первом использовании (загрузка модели), дальше основная часть приложения работает офлайн.
