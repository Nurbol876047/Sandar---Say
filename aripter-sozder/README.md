# Әліппе — қазақ әріптері мен сөздерін үйрену тренажёрі

Балаларға арналған веб-тренажёр: 42 қазақ әрпі және әр әрiпке 3–5 қарапайым сөз.
Карточканы бассаң — дыбысталады. Стек: **Node.js + таза JavaScript** (фреймворксіз).

## Орнату

```bash
npm install
```

## 1. Дыбыстарды генерациялау (бір-ақ рет)

Сайт жұмыс істеуі үшін алдымен барлық әріп пен сөзге арналған MP3 файлдарын жасау керек:

```bash
node scripts/generate-audio.js
```

Бұл скрипт `data/content.json` файлындағы әр жазбаны `edge-tts-universal`
кітапханасы арқылы (дауыс: `kk-KZ-AigulNeural`, әйел дауысы, баяу жылдамдықпен
`rate: "-15%"`) дыбыстап, `public/audio/{id}.mp3` етіп сақтайды.

- Бар файлдарды қайта жазбайды — жаңа сөз қосылса, тек соны ғана генерациялайды.
- Әріптер үшін `content.json` ішіндегі `speak` өрісі оқылады (мысалы, «Ә әрпі»),
  ол болмаса — жай `text` оқылады.

**Бұл команда тек бір рет, интернет бар кезде керек.** Одан кейін сайт толығымен
дербес істейді — интернет те, Microsoft та қажет емес, себебі барлық дыбыс
`public/audio/` ішінде дайын mp3 түрінде сақталған.

## 2. Сайтты іске қосу

```bash
npm start
```

Содан кейін браузерде ашыңыз: **http://localhost:5050**

(Портты өзгерту үшін: `PORT=8080 npm start`)

## Құрылым

```
data/content.json       — 42 әріп + әрқайсысына 3–5 сөз (id, text, type, emoji, speak)
scripts/generate-audio.js — дыбыстарды бір рет генерациялайтын скрипт
server.js                — статикалық файл серверi (фреймворксіз, таза Node.js)
public/index.html        — беттің негізгі құрылымы
public/css/style.css     — безендіру, адаптив
public/js/app.js         — карточкаларды салу, дыбысты ойнату/алдын ала жүктеу логикасы
public/audio/*.mp3       — генерацияланған дыбыс файлдары (generate-audio.js жасайды)
```

## Жаңа сөз/әріп қосу

`data/content.json` файлына жаңа жазба қосыңыз да, қайта
`node scripts/generate-audio.js` іске қосыңыз — тек жаңа қосылған жазбаларға
ғана дыбыс жасалады, барлығын қайта генерацияламайды.
